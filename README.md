# Simple Extension

SillyTavern 1.18의 기본 확장 탭을 모바일 친화적인 폴더형 목록으로 정리하는 UI 확장입니다.

## 기능

- 원본의 **확장 프로그램 업데이트 알림**, **확장 프로그램 관리**, **확장 프로그램 설치** 기능 유지
- 실리태번 원본 `#extensions_settings`, `#extensions_settings2` 설정 블록을 그대로 사용
- 실제로 동작하는 확장 이름 검색
- 이름순 / 이름 역순 / 원래 순서 / 폴더순 정렬
- 사용자 폴더 추가·이름 변경·삭제
- 확장 설정을 열어 폴더로 이동
- 원본 인라인 드로어의 클릭·펼침 기능을 변경하지 않고 디자인만 적용
- 원본 제목줄과 화살표는 숨기고 모든 확장에 동일한 고정 알약 제목줄을 표시
- 고정 알약을 누르면 숨겨진 실리태번 원본 토글을 호출해 기존 펼침 기능 유지
- 이미지 프롬프트 템플릿처럼 확장 내부에 추가로 존재하는 원본 드로어도 별도 고정 알약으로 표시
- 뒤늦게 추가되는 확장 제목줄을 변경 감지와 주기적 정규화로 다시 숨겨 중복 제목 방지
- 확장 목록에서 버전 및 임의의 켜기/끄기 토글을 표시하지 않음
- 신규 설치 시 기본 폴더를 만들지 않으며 사용자가 필요한 폴더만 직접 추가
- 확장 앞의 공통 퍼즐 아이콘을 제거한 컴팩트 목록
- 기본 테마 색상(실리태번 색상 자동 추종) / 미니멀 화이트 / 라이트 모던 / 다크 모던 / 파스텔 소프트 테마
- 웹에서는 확장 목록을 2열로 표시하고 모바일에서는 1열로 전환
- 모바일 상단 기본 기능 3개를 동일한 9px 글씨와 왼쪽 정렬의 소형 한 줄 버튼으로 표시
- 펼친 원본 설정의 가로폭·높이·overflow 제한을 풀어 내용 잘림 방지
- 펼친 콘텐츠까지 이어지는 모든 상위 껍데기의 폭·높이·overflow를 강제로 고정
- 설정 껍데기에 `width/max-width`, `height/max-height`, `overflow`, `contain` 강제 규칙을 적용해 지도·채팅형 확장의 모바일 잘림 방지
- 모바일·데스크톱 대응
- 테마가 확장 패널에 비대칭 좌우 여백을 적용해도 실제 패널 중심점을 기준으로 전체 UI 위치 자동 보정

폴더를 삭제해도 확장이나 확장 데이터는 삭제되지 않습니다. 별도의 설치 목록과 설정 화면을 매칭하지 않으며, 실리태번이 실제로 만든 설정 DOM을 그대로 재배치하고 CSS 테마만 적용합니다.

## 설치

Git 저장소의 루트에 `manifest.json`, `index.js`, `style.css`가 오도록 업로드한 뒤 SillyTavern의 **확장 프로그램 설치**에서 저장소 주소를 입력합니다.

직접 설치할 경우 `simple-extension` 폴더 전체를 아래 위치에 넣고 SillyTavern을 새로고침합니다.

`SillyTavern/data/default-user/extensions/simple-extension`

## 호환성

- SillyTavern 1.18.0 기준
- 서버 플러그인 및 외부 통신 없음
